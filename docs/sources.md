## Data conventions

- All monetary values are in USD billions.
- ACTUAL represents reported historical financial results.
- RUN_RATE represents annualized revenue, not recognized annual revenue.
- VALUATION represents private financing post-money valuation.
- LOWER_BOUND and APPROXIMATE values must not be treated as exact observations.
- Month-level dates use the first day as a placeholder, not an exact event date.
- Fiscal-year metrics use December 31 as a period-end date.
- Reuters-reported financials require reconciliation against public SEC filings when available.
